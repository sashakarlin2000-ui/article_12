# Прогнозирование фондового рынка с помощью LLM, режимов рынка и исторического поиска

## 1. Описание проекта

Проект посвящён исследованию методов прогнозирования направления движения фондового рынка с использованием больших языковых моделей (LLM), определения режимов рынка, поиска похожих исторических ситуаций и объединения прогнозов нескольких моделей.

Предлагаемая система определяет текущее состояние рынка, находит похожие ситуации в исторических данных, получает прогнозы от нескольких LLM и объединяет их в единый торговый сигнал.

Основная цель — проверить, повышает ли такой подход качество прогнозирования и устойчивость торговых результатов по сравнению с отдельными LLM и классическими моделями машинного обучения.

## 2. Главный исследовательский вопрос

**Улучшает ли поиск исторических аналогов с учётом режима рынка в сочетании с ансамблем разных LLM качество прогнозирования акций по сравнению с отдельными LLM и классическими методами?**

### Исследовательские гипотезы

* **H1:** Использование похожих исторических ситуаций улучшает прогнозы LLM по сравнению с моделями без исторического поиска.
* **H2:** Поиск исторических ситуаций внутри текущего режима рынка эффективнее поиска по всей истории без ограничений.
* **H3:** Объединение прогнозов нескольких LLM повышает устойчивость результатов по сравнению с отдельными моделями.
* **H4:** Использование разных весов моделей в зависимости от режима рынка может улучшить показатели доходности с учётом риска по сравнению с обычным ансамблем.

Все гипотезы будут проверяться экспериментально. Заранее считать их доказанными нельзя.

## 3. Архитектура системы

```text
Исторические данные рынка
          ↓
Расчёт признаков
          ↓
Определение режима рынка
          ↓
Текущий режим рынка
          ↓
Поиск похожих исторических ситуаций
          ↓
Прогнозы нескольких LLM
          ↓
Объединение прогнозов (Ensemble)
          ↓
Итоговый сигнал: UP / DOWN / HOLD
          ↓
Историческое тестирование (Backtest)
          ↓
Оценка качества и торговых результатов
```

## 4. Определение режимов рынка

В первой версии рассматриваются четыре возможных режима:

* **Bull — бычий рынок:** рынок находится в восходящем тренде.
* **Bear — медвежий рынок:** рынок находится в нисходящем тренде.
* **Sideways — боковой рынок:** цена движется в диапазоне без выраженного направления.
* **High Volatility — высокая волатильность:** наблюдаются значительные колебания цены.

Для определения режимов будут рассматриваться методы K-Means, Gaussian Mixture Models (GMM) и Hidden Markov Models (HMM).

Важно учитывать, что высокая волатильность сама по себе не определяет направление рынка. Поэтому окончательное определение режимов будет зависеть от результатов анализа данных.

## 5. План экспериментов

Для оценки эффективности подхода будут проведены следующие эксперименты:

| Эксперимент | Метод                                                                                  |
| ----------- | -------------------------------------------------------------------------------------- |
| E1          | Классическая модель машинного обучения, например XGBoost                               |
| E2          | Прогнозирование с помощью LLM без исторического поиска                                 |
| E3          | LLM с поиском похожих исторических ситуаций                                            |
| E4          | LLM с поиском исторических ситуаций внутри текущего режима рынка                       |
| E5          | Ансамбль прогнозов нескольких LLM                                                      |
| E6          | Полная система: режимно-зависимый исторический поиск и ансамбль с динамическими весами |

По возможности для всех методов будут использоваться одинаковые тестовые периоды и единые правила оценки.

## 6. Метрики оценки

### Метрики качества прогнозирования

* Accuracy — доля правильных прогнозов.
* Balanced Accuracy — сбалансированная точность.
* Precision — точность положительных прогнозов.
* Recall — полнота.
* F1-score — гармоническое среднее Precision и Recall.
* MCC — коэффициент корреляции Мэтьюса.

### Метрики торговой эффективности

* Cumulative Return — накопленная доходность.
* Sharpe Ratio — доходность с учётом риска.
* Maximum Drawdown — максимальная просадка.
* Win Rate — доля прибыльных сделок.

Качество прогнозов и прибыльность торговой стратегии будут оцениваться отдельно. При тестировании также необходимо учитывать комиссии и другие торговые издержки.

## 7. Данные и предотвращение утечки будущей информации

Проект будет использовать исторические данные фондового рынка: цены, объёмы торгов и рассчитанные технические индикаторы.

Планируемые признаки:

* Доходность за 1 и несколько торговых дней.
* Волатильность за разные периоды.
* RSI — индекс относительной силы.
* Скользящие средние.
* Расстояние цены до скользящих средних.
* Режим рынка и, при наличии, вероятность принадлежности к нему.

### Правила корректного тестирования

1. Для каждого прогноза используются только данные, доступные на момент его формирования.
2. При поиске аналогов исключаются текущая дата и все будущие даты.
3. Для определения режима используются только доступные на тот момент данные, без применения состояний, рассчитанных с использованием будущей информации.
4. Настройка моделей выполняется без использования итогового тестового периода.
5. Проверка проводится на хронологически разделённых данных или методом последовательного тестирования (walk-forward validation).

* `backtest.py` — историческое тестирование и оценка результатов.

## 10. План разработки

### Неделя 1 — Базовая инфраструктура

* Подготовить данные и признаки.
* Реализовать первую версию определения режимов.
* Разработать поиск исторических аналогов.
* Подготовить ансамбль и модуль бэктестинга.
* Согласовать форматы взаимодействия между модулями.

### Неделя 2 — Интеграция LLM

* Подключить несколько языковых моделей.
* Унифицировать формат входных данных и прогнозов.
* Объединить модули в единый конвейер.
* Запустить первые сквозные тесты.

### Неделя 3 — Основные эксперименты

* Провести сравнение базовых методов.
* Проверить пользу исторического поиска.
* Сравнить обычный поиск с режимно-зависимым.
* Оценить ансамбль нескольких LLM.

### Неделя 4 и далее — Проверка и научная статья

* Провести дополнительные тесты на разных периодах и активах.
* Проверить устойчивость результатов.
* Подготовить таблицы и графики.
* Проанализировать ограничения метода.
* Завершить научную статью.

Сроки являются предварительными и будут уточняться по мере разработки.

## 11. Ожидаемый результат

В результате проекта планируется создать экспериментальный программный прототип, который:

1. Обрабатывает исторические данные фондового рынка.
2. Определяет текущий режим рынка.
3. Находит похожие исторические ситуации.
4. Получает прогнозы от нескольких LLM.
5. Объединяет прогнозы в единый сигнал.
6. Проверяет качество прогнозирования и торговую эффективность на исторических данных.
7. Сравнивает предложенный метод с базовыми подходами.

Итогом исследования станет научная статья с описанием метода, экспериментального протокола, полученных результатов и ограничений предложенного подхода.
